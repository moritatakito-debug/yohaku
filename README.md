# YOHAKU v5 — AI Sound Studio

集中用のマスキング音を作るWebアプリです。GitHub + ロリポップ！デプロイナウで静的サイトとして公開できます。

## 起動と公開
- このリポジトリの `main` ブランチ直下にある `index.html` がアプリ本体です。
- ロリポップ！デプロイナウで「GitHub連携」から `moritatakito-debug/yohaku` を選択します。
- ブランチは `main`、フレームワークは静的サイト（Static）を選択してデプロイします。
- 発行された HTTPS URL にアクセスすると利用できます。

## 主な機能
- ホワイト・ピンク・ブラウンノイズ
- 10バンドのイコライザーと環境音ミキサー
- プリセットとレシピ保存、集中タイマー
- 周波数解析に基づく音の提案
- 学習済み音響分類AI（AST）のオンデマンド読み込みと提案機能

## 注意
- ブラウザでのマイク利用には、利用者の許可と HTTPS（または localhost）が必要です。
- 学習済みAIは初回実行時に外部CDNからライブラリ・モデルをダウンロードします。通信と端末性能によっては失敗する場合があります。
- 音声解析はブラウザ内で実施する設計です。音声自体の送信機能はありません。
- 音声分類は推定であり、騒音を完全に消すものではありません。
- App Store向けのネイティブアプリではありません。iPhoneの画面ロック時のバックグラウンド再生は環境によって制限されます。
- iPhone / Android の実機でのAI分析と音質の最終検証は未完了です。

現在の `index.html` はHTML・CSS・JavaScript一体型です。公開テスト後、必要に応じて分割・モジュール化します。
